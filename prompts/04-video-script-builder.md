# 4. Video Script Builder

**Purpose:** Write a complete, retention-optimized script — from a pattern-interrupt
hook through value delivery to a call-to-action that drives subscribers, comments,
and watch time.

## Variables to fill in

- `[topic]` — what the video is about
- `[audience]` — who it's for

## Prompt

```text
Act like a professional YouTube scriptwriter.

Write a complete script for a video about [topic], targeting [audience].

Structure it as:
1. Pattern-interrupt hook (0–15s) — a line that stops the scroll and sets a stake
2. Problem setup — name the viewer's pain and why it matters now
3. Value delivery — the core content, broken into clear, sequenced steps
4. Retention hooks — open loops or "but wait" moments between sections
5. Call to action — a natural CTA that drives subscribes, comments, and watch time

Write it in a spoken, conversational voice (not an essay). Include [B-ROLL] and
[ON-SCREEN TEXT] cues where they'd strengthen retention. Target a [8–10] minute
runtime.
```

## Pro tips

- Swap the target runtime in the last line to match your format (Shorts vs. long-form).
- Ask for 3 alternative hooks so you can pick the strongest one after reading them aloud.
- Feed in the winning title from prompt #3 so the script pays off the exact promise
  the thumbnail made.

## What you'll get back

A ready-to-record script with a strong cold open, sequenced value, retention hooks
between sections, and a CTA — plus production cues for B-roll and on-screen text.
